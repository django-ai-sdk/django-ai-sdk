01 / Setup

Create an AI agent with RAG in minutes.

1. Install

Add the package and configure Django.

Terminal 
pip install django-ai-sdk
# or
uv add django-ai-sdk
settings.py 
INSTALLED_APPS = [
    ...
    "django_ai_sdk",
]
Terminal 
python manage.py migrate

2. Define your agent

Create a class with name, model, and instructions.

agents.py 
from django_ai_sdk import Agent
from django_ai_sdk.adapters.base import Stream
from django_ai_sdk.generators import openai_responses_chat
from haystack import Pipeline

class HelpDeskAgent(Agent):
    name = "Help Desk"
    model = "gpt-5-mini"
    instructions = "You are a helpful support agent."
    llm = openai_responses_chat

    async def get_pipeline_adapter(self, thread_id=None, user=None):
        storage_adapter = await self.get_storage_adapter(thread_id)
        generator = self.get_llm()
        return Stream(
            pipeline=Pipeline(),
            generator=generator,
            storage_adapter=storage_adapter,
        )

3. Add RAG pipeline

Override methods to enable document retrieval.

agents.py 
from django_ai_sdk.rags import (
    BM25QueryExpanderRAG,
    BM25QueryExpanderRAGConfig,
)

async def get_rag_queryset(self, memory_id=None):
    if memory_id:
        return Entry.objects.filter(memory_id=memory_id)
    return Entry.objects.all()

async def get_rag_pipeline(self, memory_id=None):
    documents = await self.get_rag_documents(memory_id)
    if not documents:
        return None
    return BM25QueryExpanderRAG(
        documents=documents,
        config=BM25QueryExpanderRAGConfig(top_k=5),
    )

4. Return streaming response

Use as_view() to return an SSE response.

views.py 
from .agents import HelpDeskAgent

agent = HelpDeskAgent()

@router.post("/chat")
async def chat(request, payload: ChatRequest):
    return await agent.as_view(
        payload.messages,
        thread_id=payload.thread_id,
    )
02 / What's included

Agents

Ship an agent anywhere in your app: a view, a background task, or a raw API call, no rewiring required.

Workflows

Chain agent calls into a real process, with every step tracked, so multi-step work stays auditable, not a black box.

Subagents

Split hard problems across specialists instead of one agent doing everything, and stretching to breaking point.

Tool Calling

Give agents real capabilities: MCP servers, memory, and your own functions, all under one roof.

Streaming Responses

Answers appear as they're generated, not after a long wait, and drop straight into the Vercel AI SDK.

Conversation Storage

Every thread remembers its history automatically, so you never build message persistence yourself.

RAG Pipelines

When an agent needs to ground itself in your documents, hybrid search and query expansion are already there.

Reindexing

Documents change, so your embeddings should too, refreshed on demand without a rebuild.

File Processing

Let agents answer questions grounded in the spreadsheets, contracts, and reports your users upload.

Integrations

Let agents act on the tools your team already runs, like Zendesk, Linear, or GitHub.
