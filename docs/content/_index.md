Django AI SDK brings the same simplicity Django is known for to AI development. Define an `Agent`, wire it to a view, and get a streaming, stored, tool-ready chat endpoint with no new concepts to learn.

## Getting Started

```bash
pip install "django-ai-sdk[haystack]"
```
